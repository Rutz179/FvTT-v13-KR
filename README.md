> **Foundry Virtual Tabletop v14** 한글화 모듈 🎲🖥️

V12 모듈 업데이트가 중단되어 직접 제작한 *비공식* 한국어 로컬라이제이션입니다.
시스템 UI·설정·알림창을 모두 한국어로 표시하여, 영문 인터페이스 진입 장벽을 없애는 것이 목표입니다.

## 🚀 설치 방법

1. Foundry 설정 화면 → **Add-on Modules → Install Module** 하단의 **Manifest URL** 에 아래 주소를 붙여넣고 설치합니다.
   ```
   https://github.com/Rutz179/FvTT-v13-KR/releases/latest/download/module.json
   ```
2. Foundry를 재시작하고 **`Configuration > Game Settings > Language`** 로 이동합니다.
3. 드롭다운에서 **Korean** 선택 후 새로고침(F5) 하면 한글 UI 적용 완료!

> 설치 전 기존 언어 모듈이 활성화되어 있다면 *비활성화* 후 진행하세요.
> **v13 사용자**는 [Releases](https://github.com/Rutz179/FvTT-v13-KR/releases) 에서 v13 호환 버전(1.3.x)의 `module.json` 주소를 사용하세요.
